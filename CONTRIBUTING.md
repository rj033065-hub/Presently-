# Contributing Guidelines

Thank you for contributing to **Presently**!

## Code Conventions
* **Frontend**: Next.js 15 App Router, React 19, TypeScript strict mode, Tailwind CSS classes.
* **Backend**: Python 3.13, PEP 8 formatting via Black/Ruff, type hints on all function signatures.
* **Git Commit Messages**: Use Conventional Commits (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`).

## Development Workflow
1. Fork and clone the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`.
3. Make changes and verify tests pass (`pytest` / `npm run build`).
4. Push your branch and submit a Pull Request against `develop`.
